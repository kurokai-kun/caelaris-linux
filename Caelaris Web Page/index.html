Quickstart

Installation Guide

Get Caelaris Linux running on your physical computer or inside your favorite virtual machine in minutes.

Installing on Bare Metal Physical PC

  1. Flash the assembled caelaris-kde.iso to a USB flash drive using Rufus (select DD mode) or Ventoy or balenaEtcher.
  2. Reboot your PC and press your boot menu key (F12, F11, F8, or Esc) to select the USB drive.
  3. Select Caelaris Linux (KDE Plasma 6 - Default) from the bootloader menu.
  4. In the live desktop preview, double-click the Install Caelaris Linux icon.
  5. Follow the guided PyQt6 wizard to partition (Btrfs recommended), configure your user account, and install!

Headless Server & Homelab Quick Deployment

  1. Flash any Caelaris ISO (x86_64, ARM64 PC, or Raspberry Pi) to a USB drive or boot inside your hypervisor (Proxmox, KVM, ESXi).
  2. At the bootloader, highlight Caelaris Linux (Headless Server / Minimal CLI) or boot with systemd.unit=multi-user.target.
  3. Run the high-speed server installer: sudo caelaris-installer-cli.
  4. Select automated Btrfs subvolumes (@server, @var_lib_docker, @var_log) and set network / root credentials.
  5. Access Cockpit web management console at https://<server-ip>:9090 or administer via OpenSSH!
📖 Jump to Full Server ISO Architecture & Deployment Guide ↓

Installing on ARM64 Laptop (Snapdragon X Elite / Copilot+ PC)

  1. Download the ARM64 UEFI ISO from the ARM64 Laptops & PCs tab above.
  2. Flash the ISO to a USB 3.0+ flash drive using Rufus (select DD Image Mode) or balenaEtcher.
  3. In Windows on your Snapdragon laptop, disable BitLocker Device Encryption and reboot into UEFI BIOS firmware (hold Shift + Restart → Troubleshoot → Advanced → UEFI Firmware Settings).
  4. In UEFI Settings, temporarily disable Secure Boot (or allow Microsoft 3rd Party UEFI CA).
  5. Press F12 / Boot Menu key to select your USB drive. Caelaris Linux GRUB AArch64 bootloader will initialize and boot directly into KDE Plasma 6 or GNOME on Wayland!

Running in VMware Workstation / Fusion

  1. Create a new Virtual Machine: Choose Linux > Arch Linux 64-bit.
  2. Allocate at least 4 GB RAM, 2-4 vCPUs, and 30 GB virtual disk.
  3. Attach the Caelaris Linux `.iso` to the virtual CD/DVD drive.
  4. Boot the VM: open-vm-tools and automatic 1080p display resizing will engage automatically!

Running in Oracle VirtualBox

  1. Create VM: Type Linux, Version Arch Linux (64-bit).
  2. In Settings > System > Motherboard, make sure Enable EFI (special OSes only) is checked.
  3. In Settings > Display, allocate 128 MB Video Memory and choose VMSVGA controller.
  4. Start the VM. VirtualBox Guest Services will automatically scale the display and enable shared clipboard!

Running on Apple Silicon (M1 / M2 / M3 / M4) via UTM or Bare Metal

  1. UTM Hypervisor (Instant & 100% Native CPU Speed): Download the ARM64 ISO. In UTM, click Create a New Virtual Machine → Virtualize → Linux.
  2. Browse and select caelaris-rpi-arm64.iso. Allocate 4–8 GB RAM and at least 4 CPU cores.
  3. Enable UEFI Boot and VirtIO-GPU (Metal OpenGL/Vulkan acceleration) in VM Display settings.
  4. Boot the VM: spice-vdagentd automatically synchronizes clipboard, audio, and dynamic retina display scaling!
  5. Bare Metal Dual Boot (Asahi U-Boot): You can also install directly to an APFS container using the standard Asahi Linux installer environment pointing to the Caelaris ARM64 rootfs.

Deploying on Physical Server / Mini-PC / Workstation

Ideal for dedicated homelab servers, NAS storage rigs, local build agents, and Intel NUC / AMD Mini-PCs.

  1. Flash the ISO: Flash caelaris-kde.iso (or ARM64 ISO) to a USB 3.0+ flash drive using Rufus (DD mode), Ventoy, or balenaEtcher.
  2. Boot to Minimal / Headless Mode: Plug into your server node, power on, and at the GRUB bootloader, highlight Caelaris Linux (Headless Server / Minimal CLI) or press e and append systemd.unit=multi-user.target.
  3. Launch the High-Speed TUI Installer:
    sudo caelaris-installer-cli
  4. Storage & Subvolumes: The installer automatically configures Btrfs with dedicated subvolumes for root (@server), container storage (@var_lib_docker), and system logs (@var_log).
  5. Reboot to Production: Remove USB and reboot. Your headless server reaches a login prompt in under 3 seconds with OpenSSH and network interfaces automatically enabled!

Unattended Remote SSH Installation (No Monitor / No Keyboard Needed)

Designed for rackmount servers, headless nodes in server closets, and remote homelabs without physical peripherals.

  1. Plug in Ethernet & USB: Connect your server node to your local gigabit LAN via Ethernet and insert the bootable Caelaris USB.
  2. Power On: The live ISO automatically requests a DHCP lease, establishes IPv4/IPv6 connectivity, and brings up the live SSH installer daemon.
  3. Connect Remotely from your Laptop / Desktop:
    ssh root@caelaris-live.local

    (Or find the IP address via your router dashboard or arp -a / nmap -sn 192.168.1.0/24)

  4. Run Installation Over SSH:
    caelaris-installer-cli --headless --disk /dev/nvme0n1
  5. Type reboot. The installation completes without ever needing a physical monitor, keyboard, or mouse!

Virtual Server on Proxmox VE, KVM / QEMU, or ESXi

Maximum I/O performance and minimal hypervisor memory footprint for container hosts and virtual microservices.

  1. Create Virtual Machine:
    • OS: Linux 6.x / 5.x / 2.6 Kernel (64-bit)
    • System: Machine q35, BIOS OVMF (UEFI), QEMU Guest Agent checked
    • Disks: Bus/Device VirtIO Block or SCSI (VirtIO SCSI Single) with Discard enabled
    • CPU: host type for maximum instruction set passthrough (AES-NI, AVX2)
    • Memory: 1024 MB – 2048 MB (Caelaris server runs smoothly on 512 MB)
    • Network: Model VirtIO (paravirtualized)
  2. Attach ISO & Start: Boot the VM and execute sudo caelaris-installer-cli.
  3. Built-In Hypervisor Integration: qemu-guest-agent and virtio drivers initialize automatically, enabling clean host ACPI shutdown, instantaneous Proxmox live backups, and dynamic memory ballooning.

Raspberry Pi 5/4 & ARM64 Edge Server (Low-Power 24/7 Homelab)

Perfect for energy-efficient home servers drawing under 5W—ideal for Pi-hole, Nextcloud, Home Assistant, WireGuard, and media servers.

  1. Download ARM64 Server Image: Grab caelaris-rpi-arm64.img.xz from the Raspberry Pi release.
  2. Flash to MicroSD or NVMe SSD: Use Raspberry Pi Imager or balenaEtcher to flash the image.
  3. Headless First Boot: Insert card/drive, connect Ethernet, and power on. No HDMI monitor required.
  4. Connect via SSH:
    ssh caelaris@caelaris-rpi.local
  5. Integrated ZRAM: Zstandard-compressed ZRAM ensures seamless operation of multiple Docker containers even on 1 GB or 2 GB Raspberry Pi models.

🛠️ Post-Install Server Administration Cheatsheet

Enable Cockpit Web Dashboard:
sudo systemctl enable --now cockpit.socket

Navigate to https://your-server-ip:9090 in any web browser.

Enable Docker Engine & Container Pods:
sudo systemctl enable --now docker

Runs with native Btrfs snapshotting driver for zero-copy layer staging.

Configure Uncomplicated Firewall (UFW):
sudo ufw allow 22/tcp && sudo ufw allow 9090/tcp && sudo ufw enable

Enables SSH and Cockpit while securing all unexposed ports.

Non-Blocking Server Package Update:
yay -Syu --noconfirm

Rolling updates execute in background without reboot locks or library crashes.
